LightWeb Components made simple.

Everything React does, on custom elements and event listeners instead of a virtual DOM. Signals, a theme engine and 129 components come in the box.

0dependencies

Nothing under node_modules besides Light itself. What you install is what runs.

Nobuild step

ES modules served as they are. An importmap, or a bundler if you already have one.

JSwith types

Written in JavaScript with JSDoc. The .d.ts files ship in the package, so TypeScript reads every signature.

The name

Light, as in light DOM.

Web components come with the shadow DOM, and it makes them far more complicated than they need to be. Light turns it off. A component is a plain element in the page, with the page's CSS and the page's events, and that alone makes it a smaller and faster replacement for React.

The language

JavaScript, typed.

Light is plain JavaScript, so it runs as written, with no build step. Its types come from JSDoc, checked by TypeScript and shipped as .d.ts, so in a TypeScript project it is a typed package like any other.

The package

What is in it

View engine

View.define, mixins, lifecycle hooks, $own for cleanup, plugins. One render per element per frame.

html

Tagged templates with keyed lists, element bindings and slots in the light DOM. Prerendered markup is adopted, not replaced.

Signals

signal, computed, effect and batch. A component's state is a store of them.

Properties

A property is its default: a number, a string, a boolean, an array, an object. It reads and reflects its attribute; T.* adds an option.

env and navigation

Viewport, breakpoint, OS and colour scheme. Links are plain anchors until a router is configured.

Theme

Tokens from a theme object, five presets, skins scoped to one element, dark mode, icons from any Iconify set.

129 components

Forms, tables, charts, overlays, navigation, app shells and page sections. Each one has a demo.

light test

node:test and node:assert in the browser. The same test file runs under node or in Chromium.

A component is an object: its properties, its template, its hooks. Light makes it a custom element.

Signals

State is signals. A computed follows what it reads; an effect runs when that changes.

1import { signal, computed, effect } from "@lightstart/light/signals";
2
3const qty = signal(2);
4const price = signal(9.5);
5const total = computed(() => qty() * price());
6
7effect(() => { output.textContent = total().toFixed(2); });
8qty.set(3); // output reads 28.50
