Available Lifecycle Hooks

  • connected() - Called when component is added to the DOM
  • disconnected() - Called when component is removed from the DOM
  • willUpdate({ changedProps }) - Called before each render
  • firstUpdated({ changedProps }) - Called once after first render
  • updated({ changedProps }) - Called after each render
