Plugin System Example

This example demonstrates how to create and use plugins with @bootstrapp/light.

What are Plugins?

Plugins allow you to extend component behavior globally. They can:

  • Hook into lifecycle events (connected, disconnected, updated, etc.)
  • Add functionality to all components or specific ones
  • Implement cross-cutting concerns like logging, analytics, or validation

Plugin Structure

View.use({
  name: 'my-plugin',
  test: ({ component }) => true, // Optional: filter which components
  events: {
    connected: function() { /* this = component instance */ },
    disconnected: function() { /* ... */ },
    willUpdate: function({ changedProps }) { /* ... */ },
    firstUpdated: function({ changedProps }) { /* ... */ },
    updated: function({ changedProps }) { /* ... */ },
  }
});

Plugin Code

1. Logger Plugin

Logs all lifecycle events to the console.

const loggerPlugin = {
  name: 'logger',
  events: {
    connected() {
      log('logger', `[${this.constructor.tag}] Connected`);
    },
    disconnected() {
      log('logger', `[${this.constructor.tag}] Disconnected`);
    },
    updated({ changedProps }) {
      const props = Array.from(changedProps.keys());
      log('logger', `[${this.constructor.tag}] Updated: ${props.join(', ')}`);
    }
  }
};

2. Analytics Plugin

Tracks component usage and interactions.

const analyticsPlugin = {
  name: 'analytics',
  events: {
    connected() {
      log('analytics', `Component mounted: ${this.constructor.tag}`);
    },
    updated() {
      log('analytics', `User interaction on: ${this.constructor.tag}`);
    }
  }
};

3. Validator Plugin

Validates required properties on first render.

const validatorPlugin = {
  name: 'validator',
  test: ({ component }) => component.tag.includes('plugin-demo'),
  events: {
    firstUpdated() {
      const requiredField = this.getAttribute('required-field');
      if (!requiredField) {
        log('validator', `WARNING: Missing required-field on ${this.name}`, true);
      } else {
        log('validator', `Validation passed for ${this.name}`);
      }
    }
  }
};
