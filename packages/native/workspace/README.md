# @light/workspace

A folder as a native app works in it. `workspace.ts` opens one (`Workspace`: the folder, its git repository, its file list and its watcher). `files.ts` lists the files (git's view in a work tree, a capped walk elsewhere, the usual dependency and build folders skipped) and reads one capped and positioned (`readFileCapped`, `insidePath`). `git.read.ts` is the one wrapper every git read goes through (`git`: `--no-optional-locks`, paths as they are, a timeout); `git.ts` the repository, its status and a file at HEAD; `git-log.ts` the branches, the log, a commit's files and the bases; `git-parse.ts` the parsers of git's NUL-separated listings. `changes.ts` is what changed against a base with lines added and removed; `tree.ts` the files as a tree with marks; `watch.ts` the watcher, batching per-directory snapshots and watching the git directory apart; `window.ts` a file's lines read backwards from an offset. `folder.ts` is `FolderController`, a light controller holding the folder's files, status and compare base as snapshot signals the views read, and firing `FolderHooks` an app's plugins listen to.

Tests: `test/files.test.ts`, `test/tree.test.ts`, `test/watch.test.ts`, `test/workspace.test.ts` (`light-native test workspace`).
