# @lightstart/highlight

Syntax coloring for terminal views and the browser's `<lc-code-block>`, with nothing of light in it: a tokenizer colors one line at a time and carries a state (`HlState`) into the next, so a view colors only the lines it draws. `tokenizeLine` and `tokenizeAll` (`index.ts`) answer tokens with a style each (`TOKEN_COLORS`, One Dark); a grammar's tokenizer (`javascript.ts`, `css.ts`, `html.ts`, `markdown.ts`) lives in its own module; `registry.ts` maps file extensions and fence names to languages (`addLanguage`, `languageForPath`, `languageForFence`, `removeLanguages(owner)` for a plugin's).

A browser loads a grammar on first use: `loadLanguage(language)` imports the module for the language, fence name or extension (an unknown one resolves without loading), and `hasLanguage(language)` says whether it can tokenize synchronously yet. Until then `tokenizeLine` and `tokenizeAll` answer no tokens, so a view draws plain text and re-renders once `loadLanguage` resolves; `<lc-code-block>` does exactly that. `grammar.ts` holds the static name table, so asking for a language imports no other grammar.

A caller that must tokenize synchronously imports `@lightstart/highlight/all` (or `languages.ts`, which re-exports it): it registers every built-in grammar at once. `registerLanguages()` remains for a caller that registers at start, and `addLanguage` adds a language of the host's own.

An editor re-tokenizes as it is edited, from the changed line on: `HlState.clone()` keeps a line's outgoing state, and `HlState.equals(other)` says a line ended in the state it ended in before, where the change stops spreading. Each `Language` says how many lines after one its tokens depend on (`lookAhead`: Markdown's 1, since a table header waits for its delimiter row) and how far a new line indents after the text before the cursor (`indentAfter`).

Markdown follows CommonMark: emphasis by the delimiter stack, setext headings, indented code, tables, strikethrough, `[[wiki links]]`, `#tags` and front matter. A token that is syntax rather than text (the `**` of strong, a heading's `#`) carries `mark`, so a preview may hide it. `tokenizeLineWithStructure(language, text, state, peek)` answers a line's tokens with its `MdLine` (`markdown.ts`): its block (heading, list with its marker and checkbox, table row with its cells, fence edge, and so on), its quote depth with the `>` ranges, and its inline spans with the ranges of their delimiters, link targets and wiki names. `peek(offset)` answers a following line, or null past the end; `tokenizeAll` peeks into the lines it is given.

Tests: `test/highlight.test.ts`, `test/markdown.test.ts`, `test/imports.test.ts`, under node and natively (`light test highlight`).
