# lightstart

The unscoped install of [`@lightstart/light`](https://www.npmjs.com/package/@lightstart/light).

```bash
npm i lightstart
```

This package depends on `@lightstart/light` and re-exports its root entry. The
subpaths (`@lightstart/light/html`, `@lightstart/light/signals`, …) are imported
from the scoped package, since they name modules this alias does not mirror.

- Documentation: [lightstart.dev](https://lightstart.dev)
- Source: [github.com/alantriesagain/light](https://github.com/alantriesagain/light)
